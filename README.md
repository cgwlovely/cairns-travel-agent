# Cairns Travel Agent 2026

一套面向中文旅行者的北昆士兰公路旅行资料与生成工具，覆盖：

`Cairns Airport → Port Douglas → Cape Tribulation → Yungaburra → Cairns → Brisbane`

旅行日期为 2026 年 9 月 17 日至 26 日。内容重点包括真实地理关系的每日路线地图、景点图片、餐厅和活动选择、双人预算、住宿节奏、预订入口以及天气备用方案。

## 重要说明

- 价格、营业时间、活动班次和库存会变化，出发前必须以运营商、餐厅、酒店和航空公司的正式页面为准。
- 路线地图用于行程规划，不替代实时导航、道路封闭和天气警报。
- 大堡礁活动后的飞行间隔应遵守实际潜水项目与运营商的安全指引。
- 图片来源信息保存在各素材目录的 `credits.json` 或 `commons.json` 中；再发布或商业使用前请逐项核对许可和署名要求。
