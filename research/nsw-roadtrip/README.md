## 全程共识（跨篇）

- **春假错位是本行程最大隐性红利**：QLD 春假 9/19 起（只影响出发/返程车流和边境景点），**NSW 学校 9/25 才放假**——你们在 NSW 段全程避开人潮，住宿在低价位、海滩清净；副作用是**多数海滩救生巡逻还没开季，默认不下水**。
- **两条驾驶纪律**：高原段（D1-D4）9 点后出发、日落前进城（霜/黑冰+袋鼠）；品酒日（D5）定一个全天不喝的司机（NSW 0.05，当场吊照 3 个月）。
- **现金备好**：Bald Rock/Boonoo Boonoo 入园 $8 自助投币、Bombah 渡轮 $6.50 只收现金。
- **订房**：8 晚基本都是淡季平日，issue 的 A$1,000–1,100 预算经核证方向可信；只有 Coffs（9/24，QLD 春假中段）建议早锁。
