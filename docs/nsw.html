评分方法

目的地anchor优先约4.8–4.9且200+ reviews；4.6–4.7但1000+ reviews同样可保留。餐厅采用相同逻辑，但额外检查实际到达星期几的营业状态；高分小样本只在小镇缺乏大样本候选时使用。住宿不能只用评分：先过“private room + private bathroom + 非hostel + parking”硬门槛，再比较评分、价格和绕路成本。

顺序：候选扫描 → 评分/评论量 → 去重 → 绕路惩罚 → 精确营业日 → 住宿硬过滤 → 实时价格 → 小时级排程。
